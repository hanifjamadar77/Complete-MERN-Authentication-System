# 🔐 Complete MERN Authentication System

A full-stack authentication system built using the MERN stack with secure login, email verification, and password reset functionality. Designed with production-level practices and scalable architecture.

---

## 🚀 Features

- User Registration & Login
- Email Verification using Mailtrap
- Forgot Password & Reset Password flow
- JWT Authentication
- Secure password hashing using bcrypt
- Protected routes
- Password reset success email
- Clean UI with React + Tailwind CSS
- REST API using Express.js
- MongoDB database integration

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Framer Motion
- React Router DOM
- Zustand (State Management)

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (JSON Web Token)
- Mailtrap Email API
- bcryptjs
- dotenv
---

## ▶️ Run Locally

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2️⃣ Install dependencies

#### Backend

```
cd backend
npm install
```

#### Frontend

```
cd frontend
npm install
```

### 3️⃣ Start the application

#### Start backend

```
npm run dev
```

#### Start frontend

```
npm run dev
```

App runs at:

```
Frontend → http://localhost:5173
Backend  → http://localhost:5000
```
